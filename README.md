# Tic Tac Toe

Modern Tic-Tac-Toe game with two modes:

- **Player vs Computer** (with difficulty selector)
- **Player vs Player**

## Features
- Responsive, beautiful UI with Tailwind CSS
- Game mode and difficulty selection
- Play in your browser (open `index.html`)

## How to Run

1. Start a local server (for example, with Python):
	```bash
	python3 -m http.server 8080
	```
2. Open [http://localhost:8080](http://localhost:8080) in your browser.

## Files
- `index.html` — Main game UI
- `main.js` — Game logic (PvP and PvC)
- `style.css` — Fallback styles (Tailwind is used for main UI)
- `tailwind.css` — Tailwind CDN import
